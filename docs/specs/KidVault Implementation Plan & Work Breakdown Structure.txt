	2. Detailed Work Breakdown Structure (Task-by-Task Execution Order)
2.1 Milestone 1 Tasks (Scaffolding & Cryptography)
* Task 1.1: Initialize Android Studio project (com.example.kidvault, minSdk = 29, targetSdk = 35, Kotlin DSL).
* Task 1.2: Configure app/build.gradle.kts with Jetpack Compose BOM, Room (ksp), androidx.security:security-crypto:1.1.0-alpha06, and androidx.biometric:biometric:1.2.0-alpha05.
* Task 1.3: Implement PinSecurityManager.kt with 16-byte SecureRandom salt, 10,000-iteration PBKDF2WithHmacSHA256, and lockout timestamp tracking (KEY_LOCKOUT_UNTIL_MS).
* Task 1.4: Implement BiometricAuthHelper.kt wrapping BiometricPrompt with fallback to the 4-digit PIN pad.
2.2 Milestone 2 Tasks (Data Layer & Package Manager)
* Task 2.1: Create Room entities (AllowedApp.kt, UsageSession.kt) and AppWhitelistDao.kt (getAllowedAppsFlow(), upsertApp(), setAppEnabled()).
* Task 2.2: Implement InstalledAppScanner.kt using PackageManager.queryIntentActivities(Intent(Intent.ACTION_MAIN).addCategory(Intent.CATEGORY_LAUNCHER), 0) and filtering out system settings, installers, and KidVault itself.
* Task 2.3: Build AppRepository.kt to merge installed system packages with saved Room DB whitelist states and cache app icons to internal storage.
2.3 Milestone 3 Tasks (Kiosk Lockdown & System Receivers)
* Task 3.1: Create res/xml/device_admin_sample.xml and register KidVaultAdminReceiver in AndroidManifest.xml with BIND_DEVICE_ADMIN.
* Task 3.2: Implement LockTaskController.kt to manage dpm.setLockTaskPackages(), dpm.setLockTaskFeatures(adminComponent, LOCK_TASK_FEATURE_NONE), startKiosk(), stopKiosk(), and clearDeviceOwner().
* Task 3.3: Implement BootReceiver.kt listening for ACTION_BOOT_COMPLETED and ACTION_LOCKED_BOOT_COMPLETED to launch KidsLauncherActivity immediately on startup.
* Task 3.4: Implement ImmersiveModeHelper.kt using WindowCompat.setDecorFitsSystemWindows(window, false) and WindowInsetsControllerCompat to hide system bars on Honor MagicOS curved edges.
2.4 Milestone 4 Tasks (Jetpack Compose Screens & Navigation)
* Task 4.1: Define ChildSandboxTheme (Pastel Sky #E3F2FD surface, 24dp card shapes) and ParentAdminTheme (Dark Slate #12161F surface) in ui/theme/Theme.kt.
* Task 4.2: Build OnboardingScreen.kt (3-step pager: PIN creation -> Initial app selection -> Default Home Launcher intent & ADB status check).
* Task 4.3: Build KidsLauncherScreen.kt featuring the top remaining-time pill, 2-column oversized app grid, and 2-second pointer-input long-press detector on the corner Lock button.
* Task 4.4: Build PinAuthBottomSheet.kt with 4-dot progress indicator, shake animation via Animatable, circular 0–9 keypad, and lockout countdown display.
* Task 4.5: Build ParentDashboardScreen.kt with ADB Device Owner status card, app search & toggle list, daily time slider, and administrative exit/unregister buttons.
2.5 Milestone 5 Tasks (Timers, Curfew & Hardware QA)
* Task 5.1: Implement SessionTimerManager.kt using Kotlin CoroutineScope + Ticker tracking active screen-on foreground time and comparing current local time against the configured bedtime window.
* Task 5.2: Build TimeOutLockScreen.kt and trigger a FLAG_ACTIVITY_NEW_TASK | FLAG_ACTIVITY_CLEAR_TOP intent to pull KidsLauncherActivity to the foreground the instant time expires.
* Task 5.3: Add ParentIdleTimeoutTracker to ParentDashboardScreen so leaving the phone unattended or turning off the screen in Parent Mode automatically re-locks into Kids Mode after 60 seconds.
* Task 5.4: Execute Red-Team Escape Testing on the Honor 400 (verify notification pull-down block, 3-button/gesture navigation lock, reboot persistence, and in-game ad click interception).
